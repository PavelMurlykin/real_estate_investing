# Итоговая проверка React-интерфейса — 15 ноября 2026

Проверены общие компоненты и маршруты из `frontend/src/app/App.tsx`: публичные каталоги, формы создания и редактирования, карточки, клиенты, обе ипотечные формы и истории, аккаунт, восстановление пароля и неизвестный адрес.

## Исправленные дефекты

1. **Неявный сброс справочника.** Enter во время загрузки или после ошибки мог очистить одиночное либо множественное значение. Теперь прежний выбор сохраняется. Явный выбор уже загруженного варианта и осознанная очистка стрелками остаются доступны.
2. **Повтор загрузки справочника.** Повторный запрос не имел собственной блокировки. Добавлены защита от дублирования, состояние выполнения, сохранение поиска и возврат фокуса. Ошибка объявляется экранному диктору; закрытое поле больше не ссылается на отсутствующий список.
3. **Скрытый фокус.** Shift+Tab мог увести поле под фиксированную шапку. После выбора касанием поле также могло остаться вне экрана. Добавлены отступ прокрутки, ограничение высоты списка на коротких экранах, локальная прокрутка и восстановление видимости выбранного поля.
4. **Проверка ссылки восстановления пароля.** Сетевой сбой, HTTP 503 или некорректный ответ воспринимались как недействительный токен. Теперь доступен повтор проверки. Ответ HTTP 400 по-прежнему показывает недействительную ссылку и действие запроса новой.
5. **Разорванные ARIA-связи.** Поля банка, его предложений и ипотечной программы ссылались на сообщения об ошибках, отсутствующие в DOM. Ссылки добавляются только при наличии сообщения; постоянные подсказки сохранены.
