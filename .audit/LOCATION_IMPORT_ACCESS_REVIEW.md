## Executive Summary

Подтверждённых уязвимостей доступа в проверенной функции не выявлено. Импорт разрешён только группе `application_administrators` и суперпользователям. Роль модератора сохраняет ручное редактирование справочников, но не разрешает внешнюю синхронизацию. Сам по себе `is_staff` не предоставляет право импорта.

## Scope And Threat Model

- Защищаемые активы: общие справочники локаций и их связи с объектами приложения.
- Проверены анонимный запрос, обычный пользователь, сотрудник, модератор, администратор приложения и суперпользователь.
- Данные внешнего API считаются недоверенными; источник фиксирован сервером.
- Пользовательские записи, секреты, сброс паролей и полный аудит приложения в область проверки не входили.

Проверенный backend-набор: 67 тестов, включая роли, импорт, существующие API локаций и изоляцию тестовых аккаунтов. Полный интеграционный тест проходит через настоящие обработчики API, PostgreSQL, сессию и корректный CSRF: создаёт все четыре справочника, повторяет импорт без дублей и обновляет станцию и цвет линии. В нём заменяется только внешний сетевой ответ. Django system check успешен; `makemigrations --check --dry-run` не выявляет недостающих миграций.

React: 14 тестов, lint, TypeScript и production build успешны. Chrome: 3 сценария прошли (запрет для обычного пользователя и модератора, управление импортом для администратора на 1280 и 360 пикселях). Скриншоты проверены визуально.

Живая проверка успешно импортировала 83 российских региона и подтвердила повторный запуск без создания дублей. Полный живой сценарий городов, районов и метро не подтверждён: публичные серверы неоднократно возвращали HTTP 504 и сетевые тайм-ауты. Ошибки показываются в приложении без частичных записей. Синтаксис всех трёх запросов дочерних справочников отдельно успешно проверен сервером Overpass; его данные в приложение не загружались. В обычном браузерном запуске живой сценарий намеренно пропускается, включается только флагом `-LiveLocationImport`.

Основные места реализации: `users/roles.py` (`can_sync_external_data`), `api_v1/views.py` (`LocationDictionaryImportAPIView`), `location/views.py` (`LocationImportView`), `location/import_forms.py`, `location/osm_import.py`.
