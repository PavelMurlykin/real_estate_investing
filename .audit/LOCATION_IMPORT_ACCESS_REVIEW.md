## Executive Summary

Подтверждённых уязвимостей доступа в проверенной функции не выявлено. Импорт разрешён только группе `application_administrators` и суперпользователям. Роль модератора сохраняет ручное редактирование справочников, но не разрешает внешнюю синхронизацию. Сам по себе `is_staff` не предоставляет право импорта.

## Scope And Threat Model

- Защищаемые активы: общие справочники локаций и их связи с объектами приложения.
- Проверены анонимный запрос, обычный пользователь, сотрудник, модератор, администратор приложения и суперпользователь.
- Данные внешнего API считаются недоверенными; источник фиксирован сервером.
- Пользовательские записи, секреты, сброс паролей и полный аудит приложения в область проверки не входили.

| CSRF в перенаправлении | `test_fallback_parent_selection_does_not_expose_csrf_in_redirect` | В URL перенаправления только справочник и регион |
| Интерфейс | React-тесты и Chrome на отдельном стенде | Кнопка скрыта от обычного пользователя и модератора; прямой POST получает 403 |

Повторная проверка после замены источников: 65 backend-тестов, включая роли, импорт, существующие API локаций и изоляцию тестовых аккаунтов. Интеграционный тест проходит через настоящие обработчики API, PostgreSQL, сессию и корректный CSRF: создаёт все четыре справочника, повторяет импорт без дублей и обновляет цвет линии. Отдельно проверены переименование станции с сохранением ID, привязка прежних OSM-записей, сохранение активности, откат и пакетная запись 200 городов за два SQL-запроса. В этих тестах заменяется только внешний сетевой ответ. Django system check успешен; `makemigrations --check --dry-run` не выявляет недостающих миграций.

React: 14 тестов, lint, TypeScript и production Docker build успешны. Chrome: 4 сценария прошли без пропусков (запрет для обычного пользователя и модератора, управление импортом для администратора на 1280 и 360 пикселях, полный живой импорт). Скриншоты проверены визуально.

Живая проверка новой реализации через кнопку приложения успешно импортировала 85 регионов, Санкт-Петербург, 17 районов из Wikidata и 73 станции на 6 линиях. Каждый справочник импортирован повторно: создано 0, обновлено 0; у метро также 0 новых и обновлённых линий. Все восемь запросов завершились успешно с первой попытки. Ответы источников не подменялись. Дополнительные живые сценарии Москвы и Казани также успешны; подробности в LOCATION_IMPORT_RELIABILITY.md. В обычном браузерном запуске живой сценарий пропускается; включается флагом `-LiveLocationImport`.

Основные места реализации: `users/roles.py` (`can_sync_external_data`), `api_v1/views.py` (`LocationDictionaryImportAPIView`), `location/views.py` (`LocationImportView`), `location/import_forms.py`, `location/import_service.py`, `location/open_data.py`.

## Findings

Открытых подтверждённых проблем в заявленной области проверки нет.

## Remediation Plan
