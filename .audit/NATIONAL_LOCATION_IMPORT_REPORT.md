# Общий импорт локаций России — 16 ноября 2026

## Изменения

- Проверка результата отдельного импорта больше не привязана к точному названию поставщика. Счётчики по-прежнему проверяются. Ответ с неверными счётчиками показывает ошибку, после которой кнопку можно нажать снова, в том числе после перезагрузки.
- Обновление списка больше не удерживает кнопку в состоянии ожидания. Запрос отдельного импорта ограничен 55 секундами.
- Кнопка «Найти» удалена; ввод продолжает динамически обновлять фильтры. Регион и город используют широкие колонки, на телефоне — одну колонку.
- Кнопка «Импортировать все города и районы России» не зависит от фильтров. HTTP-запрос создаёт устойчивое задание, которое исполняет отдельный `location-import-worker` без новых библиотек, Redis или Celery.
- Очередь, прогресс, счётчики и снимок российского каталога хранятся в PostgreSQL. Общая блокировка исключает параллельную загрузку; ограничение БД допускает только одно активное задание. Перезагрузка страницы восстанавливает статус. Перезапуск обработчика продолжает с последнего сохранённого города; отказ источника позволяет продолжить тем же заданием.
- Регионы и все города загружаются атомарно, затем каждый город с его районами сохраняется отдельной транзакцией вместе с контрольной точкой. Сбой не теряет предыдущие города и не оставляет частичный результат текущего города.
- Города, их административные части и типы Wikidata предварительно загружаются пакетами по 50 сущностей. Данные в HTTP-запросе не могут изменить источники или ограничить общий импорт выбранным регионом.
- Исправлен разбор Алупки внутри Ялты и городов Московской области, записанных в поле `area`; названия типов регионов не дублируются в составных именах.

## Доступ

Старт, продолжение и получение состояния доступны только `application_administrators` и суперпользователям. `is_staff`, модератор, обычный и анонимный пользователь не получают доступ. POST сохраняет session authentication и CSRF. Та же операция доступна на резервной Django-странице с теми же проверками.

## Выполненные проверки

- 82 регрессионных теста PostgreSQL прошли: полный цикл всех справочников, повторная загрузка, контрольная точка после сбоя, запуск после остановки обработчика, единственное активное задание, права и CSRF для нового API и резервной формы.
- 20 React-тестов прошли, включая неверный формат ответа, смену источника, повторное нажатие, зависшее обновление списка, восстановление прогресса после открытия страницы и продолжение после ошибки. TypeScript и ESLint прошли.
- Два сценария Chrome прошли: поиск без кнопки, ширина региона/города не менее 350 px на широком экране, ошибка формата с повторным нажатием и перезагрузкой; реальный запуск общего задания без родителей, загрузка 1117 городов, отсутствие второго задания при повторном POST и восстановление состояния после reload. Скриншоты 1280 и 360 px просмотрены.
- Проверены Django system check, отсутствие пропущенных миграций и применение `location.0008`.
- Настоящие ответы рабочего API проверены схемами Zod из исходников интерфейса: все страницы регионов (85 записей), городов (1117), районов (390 с учётом прежних записей), метро (629), а также варианты выбора соответствуют контракту.

Первый общий запуск обработал 1117 из 1117 городов: создано 989, актуализировано 2, без изменений 126. Обработаны 85 регионов и 374 записи районов: создано 183, актуализировано 3, без изменений 188. Уже существующие дополнительные записи и связи сохранены. Перезапуск контейнера во время работы сохранил контрольную точку и счётчики.

Повторное общее задание завершено: 1117 из 1117 городов. Во всех трёх справочниках `created=0`, `updated=0`; без изменений 85 регионов, 1117 городов и 374 района. В ходе проверки источник временно не ответил, задание сохранило позицию 416 и успешно продолжилось с неё под тем же ID. Данные источников не подменялись. Дополнительный повторный импорт регионов после исправления составных названий также дал ноль добавлений и обновлений.

Окончательная сборка развёрнута с четырьмя здоровыми сервисами: PostgreSQL, Django, nginx и обработчик импорта. Незавершённых проверок и известных ошибок из этой задачи не осталось; ограничения полноты источников перечислены ниже.

## Ограничения источников

Все города российского каталога загружаются независимо от наличия Wikidata. В первом запуске для 49 городов источник предоставил подходящие городские районы. Для 1068 городов подходящие сведения не найдены, в том числе 23 города не удалось однозначно сопоставить по стране, типу, имени и координатам. Это не означает отсутствия районов в действительности. Приложение показывает эти ограничения отдельно и сохраняет ранее введённые районы. Полнота и актуальность следуют открытым источникам; государственный адресный реестр не подменяется.

Руководства пользователя RU/EN обновлены. Проверочные журналы и скриншоты находятся в игнорируемой папке `outputs/national-import-*`.
