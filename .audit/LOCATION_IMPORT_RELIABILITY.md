# Проверка импорта локаций, 15 ноября 2026

## Источники и исправление

Overpass заменён открытыми источниками без ключа и регистрации:

- [HFLabs/city](https://github.com/hflabs/city): CSV российских городов по HTTPS, CC BY-SA 4.0. Проверенный каталог содержит 1117 городов и 85 регионов. Идентичность города задаётся ФИАС, региона — префиксом КЛАДР.
- [Wikidata Action API](https://www.wikidata.org/w/api.php): районы, линии и действующие станции регионального метро. Структурированные данные — [CC0](https://www.wikidata.org/wiki/Wikidata:Licensing).
- [Wikipedia Action API](https://ru.wikipedia.org/w/api.php): [схема Москвы](https://ru.wikipedia.org/wiki/Шаблон:Интерактивная_схема_Московского_метрополитена/data.json), [схема Санкт-Петербурга](https://ru.wikipedia.org/wiki/Шаблон:Интерактивная_схема_Петербургского_метрополитена/data.json), каталоги станций остальных пяти метрополитенов. Атрибуция CC BY-SA показана в приложении вместе с атрибуцией прежних OSM-записей.

Запросы выполняются последовательно, с описательным User-Agent, ограничениями времени/размера и одной повторной попыткой при временной сетевой ошибке. SPARQL, тяжёлые географические запросы и платные API не используются. Ветви Филёвской линии объединяются; общие станции не дублируются. Станции столиц привязаны к устойчивым ID страниц с обработкой перенаправлений; региональные станции — к ID Wikidata.

## Проверки

- 65 backend-тестов в отдельной PostgreSQL: реальные обработчики API, сессия и CSRF; матрица шести ролей для React API и Django; сопоставление прежних записей; повторный импорт; изменение названия и цвета; откат при конфликте; общая блокировка двух PostgreSQL-сессий; пакетная запись 200 городов за два SQL-запроса.
- 14 React-тестов, ESLint, TypeScript и production build Docker прошли.
- Полный импорт через кнопку браузера с реальными API прошёл для Санкт-Петербурга, Москвы и Казани (по четыре успешных браузерных сценария в каждом запуске). Каждый из четырёх справочников импортирован дважды, без новых или обновлённых записей на повторном запуске. Все запросы успешны с первой попытки. Скриншоты 1280 и 360 пикселей проверены визуально.
- Живое получение регионального метро подтвердило: Казань — 11 станций/1 линия, Екатеринбург — 9/1, Нижний Новгород — 15/2, Новосибирск — 13/2, Самара — 10/1.
- Рабочие контейнеры пересобраны, миграция `location.0007` применена; Django system check и проверка отсутствующих миграций прошли.

## Ограничения данных

Стабильный доступ не гарантирует официальной полноты или свежести открытых справочников. Например, Wikidata вернула 17 районов Санкт-Петербурга; существующий Кронштадтский район сохранён. Старые записи, отсутствующие в новых источниках, не удаляются и не выключаются; поэтому общий размер рабочего каталога может превышать число записей текущего импорта. Статус активности, ID и связи существующих записей сохраняются. Города без метро возвращают пустой результат; неизвестный или неоднозначный российский родитель отклоняется.

Импорт доступен только администраторам приложения и суперпользователям. Проверка доступа: [отчёт](LOCATION_IMPORT_ACCESS_REVIEW.md). Руководства [RU](../.documentation/user-manual.ru.md) и [EN](../.documentation/user-manual.en.md) обновлены.
