Старый параметр общего поиска объектов из URL продолжает работать: его значение показано как подсказка «Поиск из ссылки» с действием «Убрать». Общий сброс также снимает этот отбор. Формы создания/редактирования сохраняют обязательность выбора и серверную валидацию.

## Дополнительные исправления

- При асинхронном поиске варианты временно возвращались к исходной выборке. Теперь в том же контексте сохраняется предыдущая выдача до ответа сервера; при смене родителя старые варианты не предлагаются. Выбранная подпись остаётся видимой во время обновления. Enter после ввода выбирает найденный вариант, а Enter при открытии текущего выбора сохраняет его.
- У неизменяемых имён `app.js`/`app.css` был подтверждён HTTP-кэш на 30 дней. Подключение переведено на хешированные имена и manifest Vite, как предусмотрено [официальной схемой интеграции с backend](https://vite.dev/guide/backend-integration). Django читает manifest с кэшем по метаданным файла. Входной модуль и ленивые страницы используют одинаковый адрес, исключая повторную инициализацию приложения. После новой сборки обычная перезагрузка получает новые ресурсы.
